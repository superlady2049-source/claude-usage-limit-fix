## 三、预测大用量任务（派活前 1 分钟）

**估算（【经验规则】经验公式，系数需按你自己的数据校准）：** 预计 token ≈ 读入字数 ×2 ＋ 预计输出字数 ×4 ＋ 预计轮数 × 当前上下文 token。最后一项最容易漏：长会话里每多一轮，都要把整段上下文重读一遍。

| 估算 | 做法 |
|---|---|
| < 10 万 | 直接派，写上限 |
| 10–30 万 | 拆成并行块，每块写上限；先让便宜模型抽事实包 |
| > 30 万 | 先问使用者（拆小 / 降模型 / 不做），不要先做后报 |

- 每个 agent 派活时写明 token 上限，到上限交出已完成部分。
- **事后校准（【经验规则】）：** 记「预估 vs 实际」，连续 3 次偏差超 2 倍就调公式系数。
- 常见大头：整包读大量会话记录、多轮最强模型评审、全量测试、批量取数、长文档加多轮评审。
